# AI Limits

**Небольшая панель в системном трее Windows, которая показывает лимиты OpenAI Codex и Google Antigravity.**

[English README](README.md)

Неофициальная утилита сообщества. Она читает данные о квотах из уже установленных и авторизованных приложений. Отдельный API-ключ не нужен; запросы к моделям она не отправляет.

## Возможности

- Показывает недельные и пятичасовые квоты Codex и Antigravity в одной компактной панели.
- Обновляет данные каждые 30 секунд; вручную обновить их можно через меню значка.
- Один щелчок по значку открывает временную панель, двойной щелчок закрепляет её.
- Показывает обратный отсчёт до сброса по времени Новосибирска (UTC+7).
- Использует существующую авторизацию в Codex и Antigravity.

## Требования

- Windows x64.
- Python 3.12 и средство запуска Python `py`.
- Codex должен быть установлен и авторизован; Antigravity — установлена, авторизована и запущена, чтобы показывать её квоты.

В репозитории лежит исходный код, а не готовый установщик `.exe`. Для запуска понадобятся Python и зависимости проекта; отдельный установщик Windows не требуется.

## Запуск из исходников

1. На GitHub нажмите **Code → Download ZIP** или склонируйте репозиторий через Git.
2. Если Python 3.12 ещё не установлен, установите его.
3. Распакуйте архив в постоянную папку. Если потом переместить папку, созданный ярлык перестанет работать.
4. Откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install --upgrade pip
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& ".\.venv\Scripts\pythonw.exe" ".\app.py" --tray
```

Чтобы создать ярлык в меню «Пуск», выполните:

```powershell
& ".\.venv\Scripts\python.exe" ".\app.py" --install-shortcut
```

Автозапуск можно включить в контекстном меню значка → **Запускать вместе с Windows**. Он выключен по умолчанию и добавляет ярлык только в папку автозапуска текущего пользователя.

Чтобы закрыть программу, нажмите правой кнопкой по значку и выберите **Выход**. Чтобы отключить запуск вместе с Windows, снимите галочку **Запускать вместе с Windows** в том же меню.

## Данные и приватность

- **Codex:** программа запускает локальный `codex.exe app-server` и читает квоты и каталог моделей через существующую авторизацию Codex. Она не отправляет запросы к моделям и не требует API-ключ.
- **Antigravity:** программа находит локальный процесс language server и обращается к его службе квот через loopback (`127.0.0.1`). Локальный CSRF-токен считывается из этого процесса и используется только для обращения к его локальной службе; виджет его не сохраняет.
- Настройки интерфейса и последние данные квот хранятся в `%LOCALAPPDATA%\QuotaWidget` — в `settings.json` и `cache.json`. OAuth-учётные данные в этих файлах не хранятся.
- Локальный канал управления единственным экземпляром доступен только текущей учётной записи Windows.
- Программа не меняет системный прокси, не устанавливает службу и сама не запрашивает права администратора.

## Ограничения

Antigravity предоставляет данные квот через внутреннюю локальную службу, а не через документированный публичный API. Обновление Antigravity может изменить этот интерфейс и временно нарушить чтение квот. У нескольких моделей может быть общая квота; наличие модели в каталоге не означает, что для неё выделен отдельный лимит.

Проект не связан с OpenAI, Google или Anthropic и не одобрен ими. Названия и логотипы обозначают подключаемые сервисы. Источники сторонних изображений перечислены в [`assets/brands/SOURCES.md`](assets/brands/SOURCES.md); MIT-лицензия проекта не распространяется на эти логотипы и товарные знаки.

## Если квоты не отображаются

- **Нет квоты Codex:** запустите Codex и войдите в аккаунт, лимиты которого хотите видеть.
- **Нет квоты Antigravity:** запустите Antigravity и войдите в аккаунт. Виджет читает локальную службу, пока Antigravity работает.
- **Значок скрыт:** включите его в Windows: **Параметры → Персонализация → Панель задач → Другие значки области уведомлений**.
